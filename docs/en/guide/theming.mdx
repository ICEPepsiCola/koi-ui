# Theming

Two appearances: light and dark. Override `--color-primary` via `KoiProvider`.

## Built-in themes

`@koi-ui/tokens` ships `light` and `dark` via `data-theme`.

```tsx preview
import { KoiProvider, Button, Alert, Tag, Space } from '@koi-ui/core';

export default () => (
  <KoiProvider theme={{ name: 'light' }}>
    <Space>
      <Button color="primary">Primary</Button>
      <Button color="primary" variant="soft">Soft</Button>
      <Button color="primary" variant="outline">Outline</Button>
      <Tag>Tag</Tag>
      <Alert title="Light theme" description="data-theme applied via KoiProvider" />
    </Space>
  </KoiProvider>
);
```

Docs demos also expose a theme switcher next to the desktop/mobile toggle.

## Provider overrides

`KoiProvider.theme` writes CSS variables on the theme root:

```tsx pure
import { KoiProvider } from '@koi-ui/core';

<KoiProvider theme={{ name: 'dark', primaryColor: 'hsl(211 100% 50%)', radiusMd: '1rem' }}>
  {children}
</KoiProvider>
```

## Manual CSS

```css
:root {
  --color-primary: hsl(211 100% 50%);
  --color-primary-foreground: hsl(0 0% 100%);
  --radius-md: 0.75rem;
}

html[data-theme='dark'] {
  /* or any subtree */
}
```

## Dark mode

Built-in dark tokens follow `html.dark` / `html.rp-dark` / `data-theme="dark"`.

```css
html.dark {
  --color-surface: hsl(222 47% 11%);
  --color-surface-foreground: hsl(210 40% 98%);
}
```

`@koi-ui/core/styles.css` includes tokens by default. Tokens only:

```css
@import "@koi-ui/tokens/theme.css";
```

## Semantic colors

| Token | Role |
|-------|------|
| `--color-primary` | Brand |
| `--color-success` / `--color-warning` / `--color-info` / `--color-error` | Status |
| `--color-surface` / `--color-muted` / `--color-border` | Surfaces |
| `--radius-sm/md/lg` | Radius |

Component APIs use `color="error"` (daisyUI-aligned).

## Materials & motion

Floating panels and bottom sheets use frosted **material** surfaces backed by CSS variables:

| Token | Role |
|-------|------|
| `--material-regular-bg` / `--blur-regular` | Dropdowns, float menus (`FloatMenu`, `floatPanel`) |
| `--material-thick-bg` / `--blur-thick` | Bottom sheets (`MotionPanel` `variant="bottom"`, `sheetSurface`) |

`prefers-reduced-transparency: reduce` falls back to opaque surfaces and disables blur.

Overlay enter/exit uses **spring** presets from `@koi-ui/core` motion (`springSnappy` for float menus, `springMomentum` for bottom sheets) instead of fixed 200ms linear easing.

## Appearance language

Shared reading across controls:

- **solid / primary** — filled
- **soft** — tinted background
- **outline** — border only
- **ghost** — minimal / text

`Button` / `Alert` / `Tag` / `Badge` use `color` × `variant`. `NoticeBar` / `Progress` / `Toast` / `Notification` / `Result` use semantic color tokens.

## Breakpoint provider

`KoiProvider` can change the mobile breakpoint (default `lg` = 1024px):

```tsx preview
import { KoiProvider, Button } from '@koi-ui/core';

export default () => (
  <KoiProvider breakpoint="md">
    <Button>Breakpoint md (768px)</Button>
  </KoiProvider>
);
```
