# DatePicker 日期选择

## 基础用法

```tsx preview
import { DatePicker } from '@koi-ui/core';
import { useState } from 'react';
export default () => {
  const [v, setV] = useState('');
  return (
    <div className="w-full max-w-xs">
      <DatePicker value={v} onChange={setV} placeholder="选择日期" />
    </div>
  );
};
```

## 受控日期

```tsx preview
import { DatePicker, Text } from '@koi-ui/core';
import { useState } from 'react';
export default () => {
  const [date, setDate] = useState('2026-07-12');
  return (
    <div className="w-full max-w-xs">
      <DatePicker value={date} onChange={setDate} placeholder="选择日期" />
      <Text muted className="mt-2 block text-sm">选中：{date || '未选择'}</Text>
    </div>
  );
};
```

## 年 / 月 / 周

`picker` 切换粒度。周值为 ISO 周：`YYYY-Www`。

```tsx preview
import { DatePicker, Space } from '@koi-ui/core';
import { useState } from 'react';
export default () => {
  const [year, setYear] = useState('2026');
  const [month, setMonth] = useState('2026-07');
  const [week, setWeek] = useState('2026-W28');
  return (
    <Space direction="vertical" size="middle" className="w-full max-w-xs">
      <DatePicker picker="year" value={year} onChange={setYear} placeholder="选择年" />
      <DatePicker picker="month" value={month} onChange={setMonth} placeholder="选择月" />
      <DatePicker picker="week" value={week} onChange={setWeek} placeholder="选择周" />
    </Space>
  );
};
```

## 禁用日期

`disabledDate` 与 Calendar 一致：返回 `true` 的日期在日历上灰掉且不可点（也会遵守 `min` / `max`）。

```tsx preview
import { DatePicker } from '@koi-ui/core';
import { useState } from 'react';

/** 示例：仅周二、周五可选（开奖日） */
function isDrawDay(date: Date) {
  const day = date.getDay();
  return day !== 2 && day !== 5;
}

export default () => {
  const [v, setV] = useState('');
  return (
    <div className="w-full max-w-xs">
      <DatePicker
        value={v}
        onChange={setV}
        disabledDate={isDrawDay}
        clearable
        placeholder="仅开奖日可选"
      />
    </div>
  );
};
```

## 日期范围

可用 `range`，或 `DatePicker.RangePicker`。桌面端为**双月面板**；`placeholder` 可传 `[开始, 结束]`。

```tsx preview
import { DatePicker, Text, Space } from '@koi-ui/core';
import { useState } from 'react';
export default () => {
  const [range, setRange] = useState<[string, string]>(['', '']);
  return (
    <Space direction="vertical" size="middle" className="w-full max-w-xl">
      <DatePicker.RangePicker
        value={range}
        onChange={setRange}
        clearable
        placeholder={['开始日期', '结束日期']}
      />
      <Text muted className="text-sm">
        {range[0] && range[1] ? `${range[0]} ~ ${range[1]}` : '未选择'}
      </Text>
    </Space>
  );
};
```
