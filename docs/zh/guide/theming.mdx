# 主题定制

两套外观：浅色与深色。通过 `KoiProvider` 覆盖 `--color-primary`。

## 内置主题

`@koi-ui/tokens` 提供 `light` 与 `dark`，通过 `data-theme` 应用。

```tsx preview
import { KoiProvider, Button, Alert, Tag, Space } from '@koi-ui/core';

export default () => (
  <KoiProvider theme={{ name: 'light' }}>
    <Space>
      <Button color="primary">主按钮</Button>
      <Button color="primary" variant="soft">轻量</Button>
      <Button color="primary" variant="outline">描边</Button>
      <Tag>标签</Tag>
      <Alert title="浅色主题" description="通过 KoiProvider 应用 data-theme" />
    </Space>
  </KoiProvider>
);
```

文档演示区在桌面/移动切换旁提供主题切换。

## Provider 覆盖

`KoiProvider.theme` 会把变量写到主题根节点：

```tsx pure
import { KoiProvider } from '@koi-ui/core';

<KoiProvider theme={{ name: 'dark', primaryColor: 'hsl(211 100% 50%)', radiusMd: '1rem' }}>
  {children}
</KoiProvider>
```

## 手动覆盖 CSS

```css
:root {
  --color-primary: hsl(211 100% 50%);
  --color-primary-foreground: hsl(0 0% 100%);
  --radius-md: 0.75rem;
}

html[data-theme='dark'] {
  /* 或任意子树 */
}
```

## 暗色模式

暗色 Token 跟随 `html.dark` / `html.rp-dark` / `data-theme="dark"`：

```css
html.dark {
  --color-surface: hsl(222 47% 11%);
  --color-surface-foreground: hsl(210 40% 98%);
}
```

默认通过 `@koi-ui/core/styles.css` 引入；若只要 tokens：

```css
@import "@koi-ui/tokens/theme.css";
```

## 语义色

| Token | 用途 |
|-------|------|
| `--color-primary` | 品牌色 |
| `--color-success` / `--color-warning` / `--color-info` / `--color-error` | 状态色 |
| `--color-surface` / `--color-muted` / `--color-border` | 表面 |
| `--radius-sm/md/lg` | 圆角 |

组件 API 统一用 `color="error"`（与 daisyUI 一致）。

## 材质与动效

浮层与底部 sheet 使用磨砂 **material** 表面，由 CSS 变量驱动：

| Token | 用途 |
|-------|------|
| `--material-regular-bg` / `--blur-regular` | 下拉、浮层菜单（`FloatMenu`、`floatPanel`） |
| `--material-thick-bg` / `--blur-thick` | 底部 sheet（`MotionPanel` `variant="bottom"`、`sheetSurface`） |

`prefers-reduced-transparency: reduce` 时回退为不透明表面并关闭模糊。

Overlay 进出场使用 **spring** 预设（`springSnappy` 浮层、`springMomentum` 底部 sheet），而非固定 200ms 线性缓动。

## 外观读法

跨组件统一：

- **solid / primary** — 实心
- **soft** — 浅底
- **outline** — 描边
- **ghost** — 幽灵/弱化

`Button` / `Alert` / `Tag` / `Badge` 均为 `color` × `variant`。`NoticeBar` / `Progress` / `Toast` / `Notification` / `Result` 使用语义色 token。

## 断点 Provider

`KoiProvider` 可改移动端分界断点（默认 `lg` = 1024px）：

```tsx preview
import { KoiProvider, Button } from '@koi-ui/core';

export default () => (
  <KoiProvider breakpoint="md">
    <Button>断点改为 md (768px)</Button>
  </KoiProvider>
);
```
